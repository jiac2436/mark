# 地图 Mark 需求讨论纪要

## 会议结论

- 产品定位：公开用户使用的公共地图随手笔记工具。
- 第一版目标：做可交互原型，不接真实后端，不做微信登录、云开发、服务端审核或真实多人同步。
- 首页形态：进入小程序后直接看到地图，整体视觉为清爽工具感。
- 数据策略：内置公共示例标记；用户自己的标记和投票写入本机 `wx` storage。
- 权限策略：首次进入请求定位；拒绝或失败后进入浏览模式，可查看、筛选、搜索位置，但不可创建、点赞或点踩。

## 第一版功能清单

- 应用名称：地图 Mark。
- 默认兜底区域：定位失败时展示上海人民广场，示例标记围绕该区域分布。
- 地图能力：使用微信小程序官方 `map` 组件、`wx.getLocation`、`wx.chooseLocation` 和 `MapContext` 能力。
- 分类：固定为发现、提醒、吐槽、求助；创建时分类必选，标题和描述可为空。
- 空内容展示：如果标题和描述都为空，按分类显示默认文案，例如“一个提醒标记”。
- 聚合：标记按 20m * 20m 网格聚合；聚合点使用圆点 + 数量展示，数量越多红色越深。
- 筛选：按分类筛选后重新计算聚合点和数量。
- 创建：授权定位后点击顶部“新增标记”，调用微信小程序内置 `wx.chooseLocation` 选择位置；选择完成后进入分类、标题、描述表单；创建成功后新标记短暂高亮，再回归聚合。
- 第三方地图服务：第一版不接入额外地图 SDK 或第三方 WebService，避免个人开发者资质限制影响原型验证。
- 浏览：点击地图标记点后，若该点只有 1 条标记则直接展示详情；若数量大于 1，则以列表展示该区域所有标记，并可点选查看详情。
- 排序：搜索位置后优先按距离排序；其次按综合分；最后按标记时间。
- 投票：每个本机用户对每条标记只能赞或踩一次，再次点击取消，切换时自动调整；对外只展示综合分。
- 自己标记：别人看不到作者信息；本机用小徽标识别自己发布的标记，并支持删除。
- 举报：公共标记详情保留举报入口，原型阶段仅本地提示。

## 验收场景

- 授权定位成功后，可浏览、筛选、搜索、通过微信内置位置选择器创建、点赞、点踩和删除自己的标记。
- 拒绝定位后，可浏览、筛选、搜索；创建和投票时提示需要开启定位。
- 同一 20m 区域多条标记会聚合为一个点，数量和颜色随筛选、创建、删除即时刷新。
- 重启小程序后，自己的标记和投票状态仍然保留。
- 标题和描述为空时仍可提交，并展示分类默认文案。
